# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and focus on
what is best for the community. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behavior privately to the maintainers through
[GitHub private reporting](https://github.com/liimitedinfinity/kerio-vpn/security/advisories/new)
or by contacting a maintainer directly. All reports are handled confidentially, and
maintainers may remove, edit or reject contributions that do not follow this code.
